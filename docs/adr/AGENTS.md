# ADR 작업 지도

중요한 기술 선택을 조회·기록할 때 적용한다. 현재 규칙과 개발 절차는 개발 가이드에서 확인한다.

- 번호·파일명은 유지한다. 제안(proposed)은 논의에 따라 수정하고, 채택(accepted)된 결정의 변경은 새 ADR로 연결한다. 채택은 팀 합의 후 반영한다.
