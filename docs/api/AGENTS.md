# API 작업 지도

API 구현·계약을 변경할 때 적용한다.

- HTTP 계약은 [api-contract.md](api-contract.md)가 원본이다. 기능 시나리오와 중복 작성하지 않고 링크한다. 계약 변경은 프론트엔드와 합의한다.

| 상황 | 진입점 |
| --- | --- |
| 경로·요청·응답·오류 계약 확인 | [API 계약](api-contract.md) |
| 계약 작성·보완 | [작성 기준](api-contract.md#문서-작성-기준) |
| 기능 동작·시나리오 변경 | [OpenSpec 지침](../../openspec/AGENTS.md) |
