# API 문서

[api-contract.md](./api-contract.md)에서 사용자가 제공한 팀 API 명세를 기준으로 API 목록, 공통 계약과 기능별 동작을 관리한다.

## 작성 규칙

- API를 변경하면 계약도 함께 갱신한다. 문서가 커지면 기능별 파일로 나누고 계약 문서에서 연결한다.
- 각 API에는 메서드·경로, 인증·헤더, 입력 타입·필수값·제약·기본값, 요청·응답 예시, 상태 코드와 오류 조건을 적는다.
- 합의되지 않은 항목은 `미정`으로 표시한다. 계약 변경은 프론트엔드와 합의하고 구현에 반영한다.
- 예시에 비밀번호·토큰 등 비밀값을 넣지 않는다.
- 기술 선택과 설계 결정의 이유는 [ADR](../adr/README.md)에 기록한다.
