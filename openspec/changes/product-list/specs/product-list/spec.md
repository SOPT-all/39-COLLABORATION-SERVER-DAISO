# Spec Delta

## Purpose

상품 전체 목록과 상품명·품번 검색 결과를 제공한다. 클라이언트가 추가 표시 변환 없이 사용할 수 있도록 상품 정보와 저장된 공유 좋아요 상태를 일관된 계약으로 반환한다.

## ADDED Requirements

### Requirement: 상품 목록 조회
시스템은 SHALL [상품 목록 계약](../../../../../docs/api/api-contract.md#6-상품-목록-조회)에 따라 조건에 맞는 모든 상품을 상품 ID 오름차순으로 반환한다.

#### Scenario: 전체 조회
- **WHEN** 검색어를 생략하거나 빈 문자열 또는 공백만 전달한다
- **THEN** 재고 연결 여부와 관계없이 전체 상품을 페이지네이션 없이 반환한다

#### Scenario: 결과 없음
- **WHEN** 상품이 없거나 검색 조건에 맞는 상품이 없다
- **THEN** 성공 응답의 상품 목록은 빈 배열이다

#### Scenario: 일관된 정렬
- **WHEN** 여러 상품이 조회된다
- **THEN** 검색 유무에 관계없이 상품 ID 오름차순으로 반환한다

### Requirement: 상품 검색
시스템은 SHALL 앞뒤 공백을 제거한 검색어로 상품명 부분 일치 또는 품번 정확 일치를 적용하며 검색 특수문자를 일반 문자로 취급한다. 영문 비교는 API 계약의 DB 비교 기준을 따른다.

#### Scenario: 상품명과 품번 검색
- **WHEN** 검색어가 상품명 일부 또는 품번 전체와 일치한다
- **THEN** 두 조건 중 하나라도 만족하는 상품을 중복 없이 반환한다

#### Scenario: 숫자 검색과 앞자리 0
- **WHEN** 앞자리에 0이 있는 숫자 검색어를 전달한다
- **THEN** 품번을 숫자로 변환하지 않고 문자열로 정확 비교하며 상품명 부분 일치도 함께 적용한다

#### Scenario: 검색어 공백 제거
- **WHEN** 상품명 또는 품번의 앞뒤에 공백을 붙여 검색한다
- **THEN** 공백 없이 검색한 결과와 같다

#### Scenario: 검색 와일드카드 문자
- **WHEN** 검색어에 퍼센트 또는 밑줄 문자가 포함된다
- **THEN** 해당 문자를 포함하는 상품명 또는 정확히 일치하는 품번을 검색하며 다른 문자 전체로 확장하지 않는다

### Requirement: 화면 표시용 상품 정보
시스템은 SHALL API 계약의 응답 필드·표시 형식을 적용하고 상품별 저장된 좋아요 상태와 이미지 URL을 제공한다.

#### Scenario: 표시 경계값
- **WHEN** 가격과 리뷰 수가 0 또는 천 단위 구분·리뷰 수 상한의 경계값이다
- **THEN** 계약의 쉼표·가격 단위·리뷰 수 상한 표기 규칙을 적용한다

#### Scenario: 좋아요 변경 후 조회
- **WHEN** 상품 좋아요 변경 요청이 성공한 뒤 목록을 조회한다
- **THEN** 해당 상품에 저장된 좋아요 상태가 목록에 반영된다

#### Scenario: 실제 이미지와 대체 이미지
- **WHEN** 실제 상품 이미지 URL 또는 이미지 없음 안내 이미지 URL이 저장되어 있다
- **THEN** 저장된 URL을 그대로 반환하며 이미지 필드를 누락하거나 null·빈 문자열로 대체하지 않는다

### Requirement: 상품 이미지 필수 저장
시스템은 SHALL API 계약의 이미지 필수 정책에 따라 상품 이미지가 null인 상태의 저장을 허용하지 않는다.

#### Scenario: 이미지 누락 저장 거부
- **WHEN** 상품 이미지 URL을 null로 저장하려 한다
- **THEN** 저장을 거부한다

### Requirement: 조회 실패 응답
시스템은 SHALL 예상하지 못한 조회 실패에서 [공통 응답 계약](../../../../../docs/api/api-contract.md#23-공통-응답)의 서버 오류 응답을 반환하고 내부 정보를 노출하지 않는다.

#### Scenario: 서버 내부 오류
- **WHEN** 조회 처리 중 예상하지 못한 서버 오류가 발생한다
- **THEN** 계약의 서버 오류 응답을 반환한다
